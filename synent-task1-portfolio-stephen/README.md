# Portfolio Website

A responsive portfolio website with a home section, skills, a projects section (placeholders),
and a contact form with JavaScript validation.

## Built with
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (form validation)

## How to run
Open `index.html` in any browser. No install needed.

## Features
- Responsive layout for mobile, tablet and desktop
- Navbar with a menu button on small screens
- Contact form checks name, email and message before sending
